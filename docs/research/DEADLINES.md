# Deadlines and obligations

Task 11. Written on 1 November 2026. SRC-01, SRC-02, SRC-06, and SRC-11 were opened again that night. SRC-04 was opened only to see whether it states a user deadline. Source ids are in [SOURCES.md](SOURCES.md). The sequence is in [PROCEDURE.md](PROCEDURE.md).

A row is a time limit, a processing stage that names a time, a fee, or an obligation one of those pages states. [MVP_SCOPE.md](../product/MVP_SCOPE.md) says whether the first release uses it. It is not the official rule. Sign-in, the notice channels, and TARI stay in Tasks 12 and 13. This file is not a rule the agent may state. Task 14 is still the human review. The review status of every row is unreviewed.

Where two pages do not use the same words, both are kept. A count is not converted. `Not stated` means the page does not say that the item is a fixed rule or a service estimate, or does not state an exception. The statutes and circulars cited from these pages were not opened. No number in this file comes from them.

SRC-04 says that from 29 January 2024 a person registered on the IO app receives updates there. That is the start of a notice channel. It states no user deadline. It is not a row. The channel stays in Task 12.

The guide names the states "Bozza", "Aperta", "In attesa di convalida", "In lavorazione", "Sospesa", and "Integrata". None of those names a number of days. They stay in the procedure file.
